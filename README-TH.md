# NP Studio Web — รุ่น Local

## เปิดใช้งาน
1. แตก ZIP ลงโฟลเดอร์บนเครื่อง Windows แล้วเปิด `Open-Web.cmd`
2. เว็บทำงานที่ http://127.0.0.1:4173/ หากปิดเครื่องแล้วให้เปิดไฟล์นี้อีกครั้ง
3. ถ้าจะเปิดหลังบ้านแอดมิน ให้เปิด `Open-Admin.cmd` แยกต่างหาก ระบบจะเปิดหน้า NP Admin โดยตรง
4. บัญชีแอดมินครั้งแรกอยู่ใน `data/np/admin-initial.json` โปรแกรมสุ่มรหัสเฉพาะแต่ละฐานใหม่ ไม่ใช้บัญชี BMK
5. ปิดเซิร์ฟเวอร์ด้วย `Stop-Web.cmd` หรือเริ่มใหม่ด้วย `Restart-Web.cmd`

## แพ็กเกจและสิทธิ์ผู้ใช้
เข้า “แพ็กเกจ” เพื่อกำหนดสิทธิ์หลักที่ต้องขาย เช่น 5 ช่อง TikTok, 10 วิดีโอ, 1 เครื่อง พร้อมวันเริ่มใช้งานและวันสิ้นสุด หากไม่กรอกวันสิ้นสุดคือใช้งานตลอดชีพ ระบบมีแพ็กเกจเริ่มต้น `Starter` ให้แล้ว และแอดมินสร้าง/แก้แพ็กเกจเพิ่มได้โดยไม่ต้องเพิ่ม field ที่รกเกินจำเป็น

เข้า “ผู้ใช้และ License” → “สร้างรหัสผู้ใช้” ตั้ง Username, Password และเลือกแพ็กเกจ ระบบสร้าง License ให้อัตโนมัติ บันทึกข้อมูลทั้งสามเป็นรูป PNG ได้ทันทีหลังสร้าง Password แสดงครั้งเดียวในหน้าผลลัพธ์

ในหน้าแก้ไขผู้ใช้ แอดมินทำได้จากจุดเดียว: เปลี่ยน Password, เปลี่ยนแพ็กเกจ, ปรับจำนวนเครื่อง/ช่อง/วิดีโอเฉพาะราย, ระงับบัญชี, ปลดล็อกเครื่องเพื่อให้ผู้ใช้ล็อกอินเครื่องใหม่ และเพิ่มสิทธิ์อีก 1 เครื่องเมื่อต้องการ

## การบังคับสิทธิ์
ผู้ใช้ต้องกรอก License + Username + Password ครบทั้งสามรายการ เมื่อสำเร็จครั้งแรก ระบบผูกสิทธิ์กับ Windows เครื่องนั้น หากเครื่องไม่ตรงจะเข้าไม่ได้จนกว่าแอดมินจะปลดล็อกเครื่อง

ค่า `channelLimit` และ `videoLimit` ถูกส่งกลับมากับ license status เพื่อให้ runtime ใช้จริง ตอนเริ่มไลฟ์หรือปรับ config หากจำนวนวิดีโอเกินแพ็กเกจ ระบบจะปฏิเสธทันที ส่วนจำนวนช่องถูกใช้เป็นเพดานการไลฟ์พร้อมกันของ runtime

## ประกาศ
เข้า “ประกาศ” เพิ่มหัวข้อ ข้อความ และรูป PNG/JPEG/WebP ไม่เกิน 1 MB เปิดประกาศแล้วบันทึก ผู้ใช้ที่เข้าสู่ระบบ Studio จะได้รับป๊อปอัปภายในประมาณ 15 วินาทีเมื่อแท็บเปิดอยู่ ดาวน์โหลดรูปประกาศได้ กดรับทราบแล้วจะไม่แสดงประกาศฉบับเดิมซ้ำในเบราว์เซอร์นั้น การแก้ไขและบันทึกประกาศใหม่จะแจ้งอีกครั้ง

## ฐานข้อมูลและการผูกเครื่อง
ใช้ SQLite ของ NP ที่ `data/np/np.sqlite` ไม่เชื่อม MongoDB หรือข้อมูล BMK รหัสผ่านเก็บเป็น scrypt hash การผูกเครื่องทำใน transaction และคงอยู่หลังรีสตาร์ท เก็บโฟลเดอร์ `data` ไว้เพื่อรักษาฐานผู้ใช้ แพ็กเกจ และ session เดิม สำรองเมื่อหยุดเซิร์ฟเวอร์แล้ว

การระบุเครื่องใช้ Windows MachineGuid ผ่านตัวบริการ local ไม่ใช่ cookie ของหน้าเว็บ การติดตั้ง Windows ใหม่อาจถูกมองเป็นเครื่องใหม่ และผู้ที่ควบคุม Windows/ไฟล์ฐานข้อมูลเองสามารถแก้ไขระบบ local ได้ จึงไม่ใช่การล็อกฮาร์ดแวร์ที่ปลอมแปลงไม่ได้

รุ่นนี้ใช้จำลองบนเครื่องเดียว หากขายให้หลายเครื่องต้องย้ายการออกและตรวจสิทธิ์ไปฐานส่วนกลางเดียวกันก่อน การแจกฐาน local อิสระให้แต่ละเครื่องไม่สามารถบังคับ 1 License / 1 เครื่องข้ามสำเนาฐานได้

## การตรวจสอบ
ทดสอบนโยบายด้วย `runtime\node.exe tests\np-policy.test.cjs` ทดสอบชื่อผู้ใช้/รหัสผ่าน/License แพ็กเกจ โควตา การปลดล็อกเครื่อง การคงผูกหลังรีสตาร์ท และประกาศ การทดสอบสร้างฐานชั่วคราวแยกจากฐานจริง

รุ่น NP ตรวจเส้นทางล็อกอิน Studio และป๊อปอัปแล้ว ไม่ได้ทดสอบยิงไลฟ์ TikTok จริงในงานรอบนี้
